# 🍅 Pomodoro Timer

A single-file Pomodoro timer built with vanilla HTML, CSS, and JavaScript.

## How to Run

No installation needed.

1. Download or clone this repo
2. Double-click `index.html` — it opens in your browser
3. That's it!

Works in Chrome, Firefox, Edge, Safari — any modern browser.

For a local server:
```bash
npx serve .
```
Then visit http://localhost:3000

## Features

- ⏱ Configurable focus & break durations
- 🔔 Audible beep when a session ends
- 🔄 Auto-transitions between focus and break
- 📋 Session history saved across page reloads (resets each new day)
- ⌨️ Keyboard shortcuts: Space = start/pause, R = reset
- 📱 Fully responsive (works on phones and laptops)
